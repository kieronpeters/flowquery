# FlowQuery Visual Direction

The approved direction is a modern, polished SaaS workspace with a dark navy foundation, restrained violet/purple accents, clear hierarchy and rounded surfaces. The product should feel like a professional project-management and engineering-delivery platform, not a direct copy of Trello or Linear.

## Core UI concepts
- Kanban-first board with backlog, in progress, review and done columns.
- Sidebar navigation for Home, My Work, Boards, Projects, Team, Agents, Reports and Settings.
- Separate Team and Agents areas to distinguish human members from AI agents and temporary contractors.
- Project overview with task metrics, sprint progress and recent activity.
- Responsive board, list, timeline and calendar views.
- Agent directory with consistent portraits, role descriptions, model and status.
- Accessible contrast, keyboard operation, clear focus states and responsive behaviour are requirements, not optional polish.
