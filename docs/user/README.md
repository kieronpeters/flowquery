# FlowQuery — User Guide

FlowQuery is a private Kanban workspace for a small team. Two human
administrators share every board, and a roster of AI specialist profiles can be
assigned work. There is no public sign-up, no organisation hierarchy and no
custom column configuration.

## Getting in

Sign in with the GitHub account that the owner has added to the allowlist. The
first successful sign-in creates your account. There is no password to remember
or reset.

## The main screens

- **Boards** — every board, newest first. Create, rename or permanently delete a
  board here, and open a board's agent-token panel.
- **Board** — five fixed columns: Backlog, To Do, In Progress, Review, Done.
  Open a task to edit it, move it, comment, or see its activity.
- **People** — every human and agent profile. You can open anyone's profile;
  you can edit your own and any agent's.
- **Agents** — the AI specialists, with a link to each profile.
- **Docs** — this guide, the AI agent documentation, and the internal
  engineering set (for administrators).

## What FlowQuery is not

No organisations, projects or workspaces. No configurable columns. No archive:
deleting a board is permanent and requires typing its name. No email
notifications. No public or anonymous board links.
