# AI tool logos

The marks on the Boards onboarding panel. They identify the assistants the
universal prompt can be pasted into; they do not imply any integration,
sponsorship or affiliation with FlowQuery.

| File | Product | Source |
|---|---|---|
| `openai.svg` | OpenAI / ChatGPT | LobeHub icons (`@lobehub/icons-static-svg`) |
| `claude.svg` | Claude | Simple Icons (`claude`) |
| `gemini.svg` | Gemini | Simple Icons (`googlegemini`) |
| `deepseek.svg` | DeepSeek | Simple Icons (`deepseek`) |
| `grok.svg` | Grok | LobeHub icons (`@lobehub/icons-static-svg`) |
| `meta-ai.svg` | Meta AI | Simple Icons (`metaai`) |
| `github-copilot.svg` | GitHub Copilot | Simple Icons (`githubcopilot`) |
| `cursor.svg` | Cursor | Simple Icons (`cursor`) |
| `cline.svg` | Cline | Simple Icons (`cline`) |
| `opencode.svg` | OpenCode | Simple Icons (`opencode`) |

Simple Icons is CC0; LobeHub icons is MIT. The brand marks themselves remain the
trademarks of their owners. The panel normalises them to a single white tone
with CSS so the row is visually balanced; the source files are not redrawn.

If a product has no suitable official mark, use a neutral fallback rather than
an inaccurate logo. Do not add a product by editing another brand's SVG.
