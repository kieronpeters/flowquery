# Decisions

The single authoritative decision register is **[`docs/DECISIONS.md`](../../docs/DECISIONS.md)**.

This file deliberately contains no decisions of its own. Two registers previously existed with slightly different wording for the same decisions, which is exactly the kind of drift that leads an agent to implement the older one.

## Where to look

| Need | Go to |
|---|---|
| Approved, proposed and open decisions with IDs and dates | `docs/DECISIONS.md` |
| A one-paragraph summary of decisions currently in force | `docs/../.flowquery/state/PROJECT_STATE.md` §Decisions in force |

## Rule

A decision that is not in `docs/DECISIONS.md` does not exist. If you find a decision recorded anywhere else — an old document, a handoff, a chat summary — either move it into the register or mark it superseded. Never rely on it from memory alone.
